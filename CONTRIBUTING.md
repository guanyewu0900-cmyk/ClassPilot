# Contributing to ClassPilot

Contributions from teachers, teaching teams, researchers, and developers are welcome.

## Ways to contribute

- Report a reproducible problem through GitHub Issues.
- Describe a classroom need or propose a feature.
- Improve documentation or translations.
- Submit a pull request with a focused change.

## Development workflow

1. Fork and clone the repository.
2. Create a branch for one change.
3. Run `npm run check` and `npm test`.
4. Submit a pull request explaining the teaching need, the change, and how it was verified.

Do not include API keys, student information, confidential teaching records, or materials that you do not have permission to redistribute.
