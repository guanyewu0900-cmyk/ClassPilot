# Data and Privacy

## Public demonstration

The public ClassPilot demonstration is intended for testing with non-sensitive example materials. Do not upload personal, sensitive, confidential, or identifiable student information.

## Local deployment

When ClassPilot runs on a local computer or school-managed server:

- Course projects and settings are stored in the user's browser.
- Uploaded files are stored in the deployment's local `uploads/` directory.
- Access to the application and files is controlled by the deployment operator.
- API keys are read from the server-side `.env` file and are not exposed to the browser.

## Cloud model requests

When an AI assistant is used, the question, configured system prompt, and relevant knowledge-base text are sent to the selected model provider. Use an institutionally approved provider and review that provider's data terms before sending sensitive material.

## Research data

The demonstration does not implement a research-data collection pipeline. Teams conducting classroom research are responsible for their own consent, governance, retention, and ethics procedures.
